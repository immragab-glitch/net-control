# متحكم النت (Net Control)

## التشغيل
افتح **Net Control** من قايمة Start أو دبل كليك على `Net Control.lnk` ← دوس **Yes** لما الويندوز يطلب صلاحية المدير.

## التثبيت في التاسك بار
1. لو فيه أيقونة قديمة متثبتة، اعمل عليها كليك يمين ← **Unpin from taskbar**.
2. افتح قايمة Start واكتب **Net Control**، وبعدين كليك يمين على البرنامج ← **Pin to taskbar**.

لو نقلت الفولدر لمكان تاني، شغّل `install_shortcut.ps1` تاني (كليك يمين ← Run with PowerShell) عشان الاختصارات تتصلح.

## الأزرار
| الزرار | بيعمل إيه |
|---|---|
| 🎮 وضع اللعب | يقفل النت عن **أي** برنامج مش في قايمة المسموح، وبيفضل يراقب كل 3 ثواني ويقفل أي برنامج جديد يحاول يستخدم النت. لما تقفله، كل البرامج يرجعلها النت. |
| ✓ سماح | يرجّع النت للبرنامج ويضيفه لقايمة المسموح دايماً. |
| ✗ منع | يقفل النت عن البرنامج (حتى لو وضع اللعب مقفول). |
| ⚡ أولوية عالية | يدي البرنامج أولوية في الشبكة (DSCP). مفيدة لـ Roblox، بس بتشتغل لو الراوتر بيدعم QoS. |
| ⇧ تحديد الرفع | يحدد أقصى سرعة رفع للبرنامج. ده أهم حاجة لتقليل البينج، لأن الرفع لما يتملي البينج بيعلى جداً. |
| ↺ إرجاع كل حاجة | يمسح كل القواعد اللي البرنامج عملها ويرجّع الجهاز زي ما كان. |
| 🌐 English / عربي | يقلب البرنامج كله إنجليزي أو عربي، واختيارك بيتحفظ للمرة الجاية. |

## الألوان
- **أخضر** = مسموح · **أحمر** = ممنوع · **رمادي** = برنامج نظام (مينفعش يتقفل وإلا النت كله يقع)

## المسموح من الأول
Chrome (يوتيوب)، تطبيق تيك توك، Roblox، وأشهر برامج الـ VPN.
لو الـ VPN بتاعك مش بيظهر "مسموح"، اختاره ودوس **✓ سماح** مرة واحدة.

## ملاحظات مهمة
- **Claude / Slack / ChatGPT** هيتقفلوا في وضع اللعب لو مش مسموحين. البرنامج هيوريك القايمة قبل ما يقفل أي حاجة.
- لو برنامج اتقفل وكان فاتح اتصال قبلها، ممكن يفضل شغال لحد ما تقفله وتفتحه تاني.
- تحميلات Windows Update بتشتغل من `svchost` (برنامج نظام) فالبرنامج مش بيقفلها. لو عايز توقفها وانت بتلعب: Settings ← Windows Update ← Pause updates.
- الإعدادات بتتحفظ في `config.json` جنب البرنامج.
- قواعد المنع بتفضل شغالة حتى بعد ما تقفل البرنامج أو تعمل ريستارت. عشان ترجّع كل حاجة، استخدم زرار **↺ إرجاع كل حاجة**.
